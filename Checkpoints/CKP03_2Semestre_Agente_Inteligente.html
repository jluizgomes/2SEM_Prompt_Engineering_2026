RAG como tool + Gradio

A Aula 11 é a aula integradora — lab 100%, sem conceito novo. O grupo usa o tempo para montar a aplicação final. Ao final da Aula 11, cada grupo tem uma aplicação publicada com URL pública e um agente que usa ferramentas reais. Usuário real poderia usar essa aplicação no dia seguinte.

Missão do CKP03

O grupo constrói um agente com pelo menos 3 tools, sendo 1 obrigatoriamente o RAG do CKP02 via create_retriever_tool(). A aplicação tem interface Gradio com URL pública ao vivo no momento da apresentação. Requisito mínimo: 3 tools funcionando + interface Gradio com URL pública + 3 exemplos de interação documentados + tool descriptions bem escritas. Diferencial: guardrail de input + compressão de contexto + mais de 3 tools.

🗃️
RAG como tool (obrigatório)
Pipeline do CKP02 encapsulado com create_retriever_tool() ou @tool. Tool description clara para o LLM decidir quando usar.
🛠️
2+ tools adicionais
Específicas do domínio: calculadora clínica, verificador de regulamento, buscador de protocolo, etc. Uma pode ser genérica.
🌐
Gradio com URL pública
demo.launch(share=True). Link válido durante toda a apresentação. Histórico de conversa por sessão.
📝
3 interações documentadas
3 exemplos no notebook: 1 que usa o RAG, 1 que usa outra tool, 1 que o agente decide não usar tool nenhuma.

Cronograma de Entregas Parciais

Aula integradora + entrega final

Aula 11 é 100% lab. Ao fim da aula: link do Colab no Portal FIAP + URL Gradio pública rodando. Apresentação de 10 min por grupo.
