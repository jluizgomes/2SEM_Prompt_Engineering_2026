O RAG do CKP02 usa os documentos do mesmo domínio escolhido na Aula 01. No CKP03 esse pipeline RAG vira uma tool do agente — a qualidade do CKP02 impacta diretamente o projeto final. Vale a pena medir e otimizar aqui.

Missão do CKP02

O grupo constrói um pipeline RAG completo sobre uma base de conhecimento real do seu domínio (leis, artigos, documentação técnica, regulamentos, manuais). Requisito mínimo: pipeline completo load → split → embed → store → retrieve → generate + 2 estratégias de chunking comparadas + RAGAS faithfulness calculado para cada uma. Diferencial: metadata filtering + reranking + interface Gradio simples.

📄
Base de conhecimento real
Leis, artigos científicos, regulamentos, manuais, FAQs reais do domínio. Não use dados fictícios ou Wikipedia genérica.
✂️
2 estratégias de chunking
Chunk_size 256 vs 512 vs 1024 — comparar com RAGAS e mostrar qual configuração ganhou e por quê.
🔍
nomic-embed-text + ChromaDB
client.embeddings(model='nomic-embed-text') + ChromaDB local. Único modelo de embedding aprovado.
📊
RAGAS faithfulness
Medir se as respostas estão nos documentos. Meta: faithfulness ≥ 0,7. Apresentar tabela por pergunta.

Cronograma e Entrega

Aula 05

Check-in: documentos + embeddings funcionando

Mostrar ao professor: documentos carregados, chunks gerados com pelo menos 1 configuração de splitter e 1 busca semântica retornando resultado.

Aula 06

Pipeline end-to-end rodando

Retrieve → generate funcionando. Começar a comparação de chunking e gerar as primeiras métricas RAGAS.

Aula 07 — ENTREGA

Entrega + apresentação de 8 minutos

Link do Colab no Portal FIAP antes do início da aula. Apresentação: 5 min demo do RAG ao vivo + 3 min mostrando a tabela RAGAS e a decisão de chunking.

⚠️ Atenção

  • O pipeline do CKP02 será reutilizado como @tool no CKP03 — construa modular com uma função buscar(consulta) clara.
  • Faithfulness abaixo de 0,5 indica alucinação significativa — itere no chunking antes de entregar.
  • Use exclusivamente nomic-embed-text para embeddings. Modelos de embedding pagos não são aceitos.
  • Documentos fictícios ou sem fontes citadas perdem todo o peso do critério "Base de conhecimento".
