⭐

🎯 Objetivo Pedagógico

EXERCÍCIO 03

Pipeline LCEL + Pydantic completo ⭐⭐⭐

⭐⭐⭐

🎯 Objetivo Pedagógico

🧩 Conceitos Trabalhados

🐍 Optional🐍 json.dumps() do schema🐍 Tratamento de exceção no parsing🤖 Pipeline estruturado end-to-end🤖 Schema como parte do prompt

📋 Passo a Passo no Colab

1Mostrar o schema como parte do prompt — O JSON Schema do Pydantic vai DENTRO do prompt, instruindo o formato esperado.
2Alunos completam gerar_relatorio() — Três partes: schema → prompt → chamada + parse.
3Testar com uma situação do domínio do grupo — Adaptar o texto de teste para o domínio escolhido na Aula 01.
