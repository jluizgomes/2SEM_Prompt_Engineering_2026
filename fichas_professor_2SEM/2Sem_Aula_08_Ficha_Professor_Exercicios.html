gr.ChatInterface ⭐

⭐

2Alunos completam responder_chat() — A função recebe mensagem + histórico do Gradio e devolve a resposta do LLM.
3Cada aluno testa a URL pública de um colega — Reforça que o link realmente funciona fora do ambiente de quem criou.

✅ Gabarito

return client.chat(model=MODEL_NAME,messages=msgs,options={'num_predict':300,'temperature':0.5},stream=False)['message']['content'].strip()

💻 Código Completo no Colab

Código que os alunos executarão no Google Colab. Narre cada bloco explicando o propósito de cada trecho.

2Sem_08_exercicio_01.py · Google Colab
import gradio as gr

SYSTEM='Voce e assistente do dominio do grupo.'

def responder(mensagem, historico):
    msgs=[{'role':'system','content':SYSTEM}]
    for u,a in historico:
        msgs.extend([{'role':'user','content':u},{'role':'assistant','content':a}])
    msgs.append({'role':'user','content':mensagem})
    return client.chat(model=MODEL_NAME,messages=msgs,
        options={'num_predict':300,'temperature':0.5},stream=False)['message']['content'].strip()

demo=gr.ChatInterface(fn=responder,title='Seu Assistente',examples=['O que e RAG?','Resuma este texto'])
demo.launch(share=True, quiet=True)

⚠️ Erros Comuns

1. Esquecer share=True — sem isso, a interface fica só local, sem URL pública. Solução: sempre incluir share=True no .launch().

2. Função não retorna string — o Gradio espera que a função retorne texto. Se retornar None ou dict, a interface quebra. Solução: garantir que responder() sempre retorne .strip().

3. Histórico não é preservado — se esquecer de usar o parâmetro historico da função, o chatbot não lembra da conversa. Solução: sempre incluir for u,a in historico para reconstruir o histórico.

💬 Sugestão de Discussão

Regra de segurança para reforçar: NUNCA expor API key na interface Gradio, nem em texto visível, nem em logs de erro que aparecem na tela.

EXERCÍCIO 02

gr.Blocks com painel de controle ⭐⭐

⭐⭐

🎯 Objetivo Pedagógico

🧩 Conceitos Trabalhados

🐍 gr.Blocks (context manager)🐍 gr.Dropdown, gr.Slider, gr.Button🐍 btn.click()🤖 UI customizada🤖 Parâmetros ajustáveis em tempo real

⚙️ Preparação Prévia

Nenhuma dependência nova.

📋 Passo a Passo no Colab

1Comparar ChatInterface (pronto) vs. Blocks (customizável) — 'ChatInterface é rápido, Blocks é flexível — depende do que você precisa controlar.'
2Alunos completam analisar_texto() e o layout — Conectar cada componente ao btn.click(fn=..., inputs=[...], outputs=[...]).
3Testar trocando o dropdown e o slider — Ver a interface reagir aos parâmetros em tempo real.

💻 Código Completo no Colab

Código que os alunos executarão no Google Colab. Narre cada bloco explicando o propósito de cada trecho.

2Sem_08_exercicio_02.py · Google Colab
import gradio as gr

def processar(texto, tarefa, temperatura):
    prompt=f'Tarefa: {tarefa}\n\nTexto: {texto}'
    return client.chat(model=MODEL_NAME,messages=[{'role':'user','content':prompt}],
        options={'num_predict':300,'temperature':float(temperatura)}},stream=False)['message']['content'].strip()

with gr.Blocks() as app:
    entrada=gr.Textbox(label='Entrada',lines=3)
    tarefa=gr.Dropdown(['Analisar','Resumir'],value='Analisar',label='Tarefa')
    temp=gr.Slider(0.0,1.5,value=0.3,label='Temperature')
    btn=gr.Button('Processar')
    saida=gr.Textbox(label='Resultado')
    btn.click(processar,[entrada,tarefa,temp],[saida])
app.launch(share=True, quiet=True)

⚠️ Erros Comuns

1. Componente não conectado ao btn.click() — o componente aparece na tela mas não faz nada porque não está na lista de inputs ou outputs. Solução: verificar se todos os componentes estão na chamada btn.click(fn, [inputs], [outputs]).

2. Tipo errado no Slider — se o Slider retornar string em vez de float, a chamada ao LLM falha. Solução: usar float(temperatura) na conversão.

3. Layout confuso — colocar muitos componentes sem ordem lógica confunde o usuário. Solução: usar gr.Row() e gr.Column() para organizar.

💬 Sugestão de Discussão

Esse painel de controle é o tipo de interface que um usuário não-técnico consegue usar sem saber que existe um LLM por trás — é a diferença entre um script e um produto.

EXERCÍCIO 03

Chatbot RAG com Gradio ⭐⭐⭐

⭐⭐⭐

🎯 Objetivo Pedagógico

Combinar RAG (Aulas 05-07) com interface Gradio — o antecessor direto do que será entregue no CKP03 (Aula 11).

🧩 Conceitos Trabalhados

🐍 Estado global (histórico)🐍 Função de busca de contexto integrada ao callback🤖 RAG com interface🤖 Chatbot com fontes citadas

⚙️ Preparação Prévia

Nenhuma dependência nova — reaproveita a base ChromaDB das Aulas 05-07.

📋 Passo a Passo no Colab

1Explicar a integração — A cada mensagem: buscar contexto → montar prompt → chamar LLM → mostrar na interface.
2Alunos completam chat_rag() — Atenção ao histórico global — sem ele, o chatbot não lembra da conversa entre mensagens.
3Testar com pergunta que exige o RAG e uma que não exige — Ver se a resposta muda de qualidade quando o contexto é relevante vs. irrelevante.

💻 Código Completo no Colab

Código que os alunos executarão no Google Colab. Narre cada bloco explicando o propósito de cada trecho.

2Sem_08_exercicio_03.py · Google Colab
import gradio as gr

BASE_DOCS=['Doc 1 do dominio.','Doc 2.','Doc 3.']

def buscar_docs(consulta,docs):
    prompt=f'Indices relevantes para: {consulta}\n'+"\n".join(f'[{i}] {d}' for i,d in enumerate(docs))+'\nSo os indices (ex: 0,1)'
    resp=client.chat(model=MODEL_NAME,messages=[{'role':'user','content':prompt}],
        options={'num_predict':10,'temperature':0.0},stream=False)['message']['content'].strip()
    try: return [docs[int(x.strip())] for x in resp.split(',') if x.strip().isdigit() and int(x.strip())<len(docs)]
    except: return docs[:2]

hist_global=[]

def chat_rag(mensagem,_):
    global hist_global
    ctx='\n'.join(buscar_docs(mensagem,BASE_DOCS))
    msgs=[{'role':'system','content':f'Contexto:{ctx}'}]+[m for u,a in hist_global[-3:] for m in [{'role':'user','content':u},{'role':'assistant','content':a}]]
    msgs.append({'role':'user','content':mensagem})
    resp=client.chat(model=MODEL_NAME,messages=msgs,
        options={'num_predict':300,'temperature':0.3},stream=False)['message']['content'].strip()
    hist_global.append((mensagem,resp))
    return hist_global

with gr.Blocks() as app:
    chatbot=gr.Chatbot(height=300)
    msg=gr.Textbox(label='Pergunta')
    btn=gr.Button('Enviar')
    btn.click(chat_rag,[msg,chatbot],[chatbot])
app.launch(share=True, quiet=True)

⚠️ Erros Comuns

1. Variável global não declarada — esquecer global hist_global dentro da função causa erro UnboundLocalError. Solução: sempre declarar global antes de modificar a variável.

2. Buscar contexto sem cache — buscar docs a cada mensagem funciona mas fica lento. Solução: limitar histórico com hist_global[-3:] para reduzir chamadas.

3. Formato do Chatbot incompatível — o Gradio espera tuplas (user_msg, bot_msg) no histórico. Solução: retornar hist_global como lista de tuplas.

💬 Sugestão de Discussão

Esse é literalmente o esqueleto do CKP03 (Aula 11) — RAG + Agente + interface. O que muda lá é a adição de tools e do loop de decisão do agente.
