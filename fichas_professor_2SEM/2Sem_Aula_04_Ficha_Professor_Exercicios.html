⚠️ Erros Comuns

System prompt genérico demais ('seja útil e educado') não passa no teste de restrição — o bot responde qualquer coisa, inclusive fora do domínio. É o erro mais comum e mais fácil de identificar ao vivo.

EXERCÍCIO 02

Context Engineering avançado (context rot) ⭐⭐

⭐⭐

🎯 Objetivo Pedagógico

Implementar gestão de contexto que preserva o system prompt intacto e demonstrar 'context rot' — degradação de qualidade conforme o contexto cresce.

🧩 Conceitos Trabalhados

🐍 Property (tokens_estimados)🐍 Composição: system + resumo + turns🤖 Context rot🤖 Preservação do system prompt🤖 Compressão condicional

⚙️ Preparação Prévia

Nenhuma dependência nova. Conecta diretamente com Memória (Aula 02).

📋 Passo a Passo no Colab

1Explicar por que o system prompt NUNCA deve sumir — Mesmo comprimindo o histórico, a identidade/regras do bot precisam sobreviver.
2Alunos completam _comprimir_se_necessario e chat() — Reaproveita a lógica de Summary Memory (Aula 02) com uma peça a mais: o system fixo.
3Rodar 5+ mensagens e observar tokens_estimados — Mostrar o contador crescendo mesmo com compressão ativa.

✅ Gabarito

        self.max_turns = max_turns
        self.turns = []
        self.resumo = ''

    def _comprimir_se_necessario(self):
        if len(self.turns) < self.max_turns: return
        antigos = self.turns[:-3]
        texto = '\n'.join(f'U:{u}\nA:{a}' for u,a in antigos)
        # 👉 COMPLETE AQUI: chame chat() para gerar resumo e salve em self.resumo
        # self.resumo = chat(f'Resuma em 2 frases:\n{texto}', max_tokens=80, temperature=0.0)
        pass  # Substitua esta linha
        self.turns = self.turns[-3:]

    def chat(self, msg):
        self._comprimir_se_necessario()
        # 👉 COMPLETE AQUI: construa contexto = [SystemMessage(content=self.system)]
        # contexto = [SystemMessage(content=self.system)]
        pass  # Substitua esta linha
        if self.resumo:
            contexto.append(SystemMessage(content=f'[Resumo: {self.resumo}]'))
        for u,a in self.turns:
            contexto.extend([HumanMessage(content=u), AIMessage(content=a)])
        contexto.append(HumanMessage(content=msg))
        resp = llm.invoke(contexto)
        self.turns.append((msg, resp.content))
        return resp.content

bot = ContextoCuidadoso('Voce e assistente especializado.', max_turns=3)
for msg in ['Meu nome e Carlos.','O que e context engineering?','Voce lembra meu nome?','E para que serve?','Resuma o que discutimos.']:
    resp = bot.chat(msg)
    print(f'U: {msg}\nA: {resp[:150]}\n')

⚠️ Erros Comuns

Comprimir o system prompt junto com o histórico — isso é o erro mais grave possível, porque o bot perde a própria identidade/regras no meio da conversa.

💬 Sugestão de Discussão

Anthropic chama isso de 'Context Engineering' desde 2025 — não é mais só escrever um bom prompt, é GERENCIAR o contexto como um recurso finito que se degrada com o tempo/uso.
