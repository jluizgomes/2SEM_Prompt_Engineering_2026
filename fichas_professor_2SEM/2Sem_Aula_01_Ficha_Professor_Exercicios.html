EXERCÍCIO 01

Chain LCEL com ChatOllama ⭐

⭐

🎯 Objetivo Pedagógico

Substituir chamadas manuais ao LLM por uma chain declarativa. O aluno vê o mesmo resultado do chatbot do 1º semestre saindo de ~15 linhas em vez de ~40.

🧩 Conceitos Trabalhados

🐍 Operador | (pipe)🐍 ChatPromptTemplate🐍 Dicionário de variáveis🤖 LCEL🤖 Composição de chains🤖 StrOutputParser

⚙️ Preparação Prévia

Nenhuma dependência nova além do setup padrão (langchain, langchain-ollama).

📋 Passo a Passo no Colab

1Explicar o pipe — 'É a mesma lógica do terminal Linux: cat arquivo | grep erro | wc -l — cada | passa a saída de um comando para o próximo.'
2Alunos completam o template — Substituir os comentários por ChatPromptTemplate.from_messages() com system + human.
3Testar com 2 domínios diferentes — Reforçar: chain.invoke() aceita um dict — a mesma chain serve para qualquer domínio.

✅ Gabarito

template = ChatPromptTemplate.from_messages([('system', 'Voce e especialista em {dominio}. Seja direto.'), ('human', '{pergunta}')])
chain = template | llm | StrOutputParser()

EXERCÍCIO 02

JsonOutputParser ⭐⭐

⭐⭐

🎯 Objetivo Pedagógico

Forçar saída estruturada em JSON — essencial quando a resposta do LLM vai ser consumida por outro sistema (não por um humano lendo texto).

🧩 Conceitos Trabalhados

🐍 JsonOutputParser🐍 Prompt com instrução de formato🐍 Try/except para parsing🤖 Structured output🤖 Confiabilidade de parsing

⚙️ Preparação Prévia

Nenhuma dependência nova.

📋 Passo a Passo no Colab

1Mostrar o problema primeiro — Rodar sem JsonOutputParser e mostrar o modelo 'conversando' antes do JSON — motiva a necessidade do parser.
2Alunos completam o template_json — O system prompt precisa instruir explicitamente 'responda APENAS com JSON válido'.
3Testar com texto ambíguo — Um texto onde a classificação não é óbvia — ver se o parser ainda funciona.

✅ Gabarito

chain_json = template_json | llm | JsonOutputParser()

💻 Código Completo no Colab

Código que os alunos executarão no Google Colab. Narre cada bloco explicando o propósito de cada trecho.

⚠️ Erros Comuns

JsonOutputParser quebra com JSONDecodeError quando o modelo escreve texto antes/depois do JSON (ex.: 'Claro! Aqui está: {...}'). É o gancho perfeito para antecipar o Capítulo 9 da apostila (with_structured_output, mais robusto).

💬 Sugestão de Discussão

Essa é a versão simples de saída estruturada. Na Aula 03, vocês vão trocar isso por Pydantic v2 — muito mais robusto porque valida os TIPOS dos campos, não só se é JSON válido.

EXERCÍCIO 03

Chatbot com histórico em LangChain ⭐⭐⭐

⭐⭐⭐

🎯 Objetivo Pedagógico

Reescrever o chatbot com memória (lista de mensagens manual do 1º sem) usando SystemMessage/HumanMessage/AIMessage do LangChain — a base que será refinada com estratégias de memória na Aula 02.

🧩 Conceitos Trabalhados

🐍 Classe Python com estado🐍 SystemMessage/HumanMessage/AIMessage🐍 Métodos de instância🤖 Histórico de conversa🤖 Memória conversacional (introdução)

⚙️ Preparação Prévia

Nenhuma dependência nova. Reaproveita o domínio do grupo escolhido nesta mesma aula.

📋 Passo a Passo no Colab

1Retomar a classe do 1º semestre — Mostrar a versão antiga com lista de dicts, comparar com a nova usando classes de mensagem tipadas.
2Alunos completam __init__ e chat() — self.historico começa com SystemMessage; cada chat() adiciona Human e AI ao final.
3Testar com o domínio do grupo — Esse chatbot é a base do CKP01 — reforçar que o domínio escolhido aqui é definitivo para o semestre.

✅ Gabarito

self.historico = [SystemMessage(content=persona)]
...
self.historico.append(HumanMessage(content=mensagem))
resp = llm.invoke(self.historico)
self.historico.append(AIMessage(content=resp.content))
