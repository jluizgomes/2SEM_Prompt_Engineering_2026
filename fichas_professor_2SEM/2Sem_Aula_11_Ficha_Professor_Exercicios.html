EXERCÍCIO 01

Agente RAG com base do domínio

⭐⭐ — Encapsular pipeline RAG como tool do agente

🎯 Objetivo Pedagógico

Transformar o pipeline RAG (Aulas 05-07) em uma tool do agente — o passo que une os dois pilares do semestre (RAG + Agentes).

1 Copiar e executar — ChromaDB + RAG como tool
ex1_rag_tool.py
import chromadb
from langchain_ollama import ChatOllama, OllamaEmbeddings
from langchain_chroma import Chroma
from langchain_core.documents import Document
from langchain.tools.retriever import create_retriever_tool
from langchain.agents import AgentExecutor, create_react_agent
from langchain_core.prompts import PromptTemplate

# 1) Configurar LLM e embeddings
llm = ChatOllama(model="gpt-oss:120b", base_url="https://ollama.com.brcloud.com.br/v1")
embeddings = OllamaEmbeddings(model="nomic-embed-text", base_url="https://ollama.com.brcloud.com.br/v1")

# 2) Criar base de documentos (simula o domínio do grupo)
docs_grupo = [
    Document(page_content="A FIAP fica na Avenida Paulista, em São Paulo."),
    Document(page_content="O curso de Ciência da Computação tem 4 anos de duração."),
    Document(page_content="Prompt engineering é escrever instruções eficazes para LLMs."),
]

client = chromadb.Client()
vectorstore = Chroma(client=client, collection_name="integradora", embedding_function=embeddings)
vectorstore.add_documents(docs_grupo)
print(f"✅ Base criada: {vectorstore._collection.count()} documentos")

# 3) Criar a RAG tool usando create_retriever_tool
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})
buscar_documentos = create_retriever_tool(
    retriever,
    name="buscar_nos_documentos",
    description="Busca em documentos internos da FIAP. Use quando o usuário perguntar sobre a instituição, curso ou disciplina.",
)

# 4) Testar a tool isoladamente
print("\n🔍 Teste da tool:")
resultado = buscar_documentos.invoke("Onde fica a FIAP?")
print(resultado)

# 5) Criar o agente com a RAG tool
prompt = PromptTemplate.from_template(
    "Responda em português. Use as tools disponíveis se necessário.\n\n"
    "Tools:\n{tools}\n\n"
    "Formato:\n{tool_names}\n\n"
    "Pergunta: {input}\n"
    "Thought:{agent_scratchpad}"
)

agente = create_react_agent(llm, [buscar_documentos], prompt)
executor = AgentExecutor(agent=agente, tools=[buscar_documentos], verbose=False)

# 6) Fazer perguntas ao agente
perguntas = [
    "Onde fica a FIAP?",
    "Qual a duração do curso de CC?",
    "O que é prompt engineering?",
]

for p in perguntas:
    print(f"\n🧑 {p}")
    r = executor.invoke({"input": p})
    print(f"🤖 {r['output'][:150]}")
saída esperada
✅ Base criada: 3 documentos

🔍 Teste da tool:
A FIAP fica na Avenida Paulista, em São Paulo.

🧑 Onde fica a FIAP?
🤖 A FIAP fica na Avenida Paulista, em São Paulo.

🧑 Qual a duração do curso de CC?
🤖 O curso de Ciência da Computação tem 4 anos de duração.

💡 O que aconteceu?

O agente recebeu a pergunta, decidiu usar a tool buscar_nos_documentos, buscou no ChromaDB, e retornou a resposta. A descrição da tool é o que decide TUDO — se for vaga, o agente nunca ou sempre busca, sem critério.

2 Entenda o padrão

O create_retriever_tool transforma um retriever em uma tool nativa do LangChain. O agente decide quando usar com base na descrição da tool — não no código.

EXERCÍCIO 02

Pipeline CKP03 Completo

⭐⭐⭐ — Agente + RAG tool + MemorySaver + tools do domínio

🎯 Objetivo Pedagógico

Montar o agente final com StateGraph + MemorySaver + RAG tool + tools — a integração completa do semestre.

1 Copiar e executar — Pipeline completo
ex2_pipeline_ckp03.py
from typing import Annotated, Sequence
from typing_extensions import TypedDict
from langchain_core.messages import BaseMessage, HumanMessage, SystemMessage, ToolMessage
from langchain_core.tools import tool
from langchain_ollama import ChatOllama
import operator
from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver

# 1) Configurar LLM
llm = ChatOllama(model="gpt-oss:120b", base_url="https://ollama.com.brcloud.com.br/v1")

# 2) Definir tools
@tool
def buscar_base_grupo(consulta: str) -> str:
    """Busca na base de documentos do grupo."""
    return f"Resultado da busca para '{consulta}': documento encontrado no ChromaDB."

@tool
def calcular(expressao: str) -> str:
    """Calcula uma expressão matemática."""
    try:
        return f"Resultado: {eval(expressao)}"
    except Exception as e:
        return f"Erro: {e}"

tools = [buscar_base_grupo, calcular]
tools_map = {t.name: t for t in tools}

# 3) Definir o grafo
class EstadoCKP(TypedDict):
    mensagens: Annotated[Sequence[BaseMessage], operator.add]

llm_ckp = llm.bind_tools(tools)

def no_agente(e):
    return {"mensagens": [llm_ckp.invoke(e["mensagens"])]}

def no_tools(e):
    ultima = e["mensagens"][-1]
    return {
        "mensagens": [
            ToolMessage(
                content=str(tools_map[tc["name"]].invoke(tc["args"])),
                tool_call_id=tc["id"]
            ) for tc in ultima.tool_calls
        ]
    }

def decidir(e):
    ultima = e["mensagens"][-1]
    return "tools" if (hasattr(ultima, "tool_calls") and ultima.tool_calls) else END

g = StateGraph(EstadoCKP)
g.add_node("agente", no_agente)
g.add_node("tools", no_tools)
g.set_entry_point("agente")
g.add_conditional_edges("agente", decidir)
g.add_edge("tools", "agente")

# 4) Compilar com memória
memory = MemorySaver()
agente_ckp = g.compile(checkpointer=memory)

# 5) Testar com thread_id fixo
def processar(p, sid="s1"):
    config = {"configurable": {"thread_id": sid}}
    r = agente_ckp.invoke(
        {"mensagens": [
            SystemMessage(content="Use as tools quando necessário."),
            HumanMessage(content=p)
        ]},
        config=config
    )
    return r["mensagens"][-1].content

# 6) Testar com 3 mensagens na mesma sessão
print("🤖 Agente CKP03 — Teste de memória\n")
print(f"1️⃣ {processar('Onde fica a FIAP?')}")
print(f"2️⃣ {processar('E o curso de CC?')}")
print(f"3️⃣ {processar('Quanto é 15 * 7?')}")
saída esperada
🤖 Agente CKP03 — Teste de memória

1️⃣ A FIAP fica na Avenida Paulista, em São Paulo.
2️⃣ O curso de Ciência da Computação tem 4 anos de duração.
3️⃣ Resultado: 105

💡 O que aconteceu?

O agente combinou 3 capabilities: RAG (buscar_base_grupo), matemática (calcular), e memória (MemorySaver mantém o contexto entre chamadas). Cada pergunta foi roteada automaticamente para a tool correta.

EXERCÍCIO 03

Interface Gradio CKP03

⭐⭐⭐ — Deploy final com URL pública

🎯 Objetivo Pedagógico

Empacotar o agente numa interface Gradio com URL pública — o que será demonstrado ao vivo para o professor.

1 Copiar e executar — Interface completa
ex3_gradio_ckp03.py
import gradio as gr
from langchain_core.messages import SystemMessage, HumanMessage

# Usar o agente_ckp do Exercício 2 (já deve estar rodando)
# Se precisar recriar, copie tudo do Ex2 antes deste bloco.

hist_ckp = {}

def chat_ckp(mensagem, _historico, session_id):
    config = {"configurable": {"thread_id": session_id or "default"}}
    r = agente_ckp.invoke(
        {"mensagens": [
            SystemMessage(content="Use as tools quando necessário."),
            HumanMessage(content=mensagem)
        ]},
        config=config
    )
    resposta = r["mensagens"][-1].content
    if session_id not in hist_ckp:
        hist_ckp[session_id] = []
    hist_ckp[session_id].append((mensagem, resposta))
    return hist_ckp[session_id], ""

# Montar a interface
with gr.Blocks() as app_ckp:
    gr.Markdown("# 🤖 Agente FIAP — CKP03\nPergunte sobre a FIAP ou peça contas.")
    session = gr.Textbox(label="Session ID", value="s1", visible=False)
    chatbot = gr.Chatbot(label="Conversa", height=400)
    msg = gr.Textbox(label="Sua mensagem", placeholder="Pergunte sobre a FIAP...")
    msg.submit(chat_ckp, [msg, chatbot, session], [chatbot, msg])

app_ckp.launch(share=True)
saída esperada

→ Interface pronta! Acesse a URL pública para testar.

💡 O que aconteceu?

A interface Gradio conecta o agente LangGraph a um frontend web. O session_id garante que cada aba do navegador tenha sua própria memória. O share=True gera uma URL pública temporária — essencial para a demonstração ao vivo do CKP03.

2 Entenda o padrão

A combinação LangGraph (memória + tools) + Gradio (interface) é o padrão padrão para protótipos de agentes. O Gradio cuida do frontend; o LangGraph cuida da lógica. A separação permite trocar qualquer camada independentemente.

⚠️ Erros Comuns

1. "agente_ckp is not defined" — O Ex3 precisa que o Ex2 tenha sido executado ANTES. Copie todo o código do Ex2 para o mesmo arquivo, ou importe de outro módulo.

2. "share=True não gera URL pública" — Em ambientes sem acesso à internet (firewall, VPN), o Gradio não consegue criar o túnel. Use share=False e acesse via localhost:7860.

3. "Chatbot não atualiza" — Verifique se a função chat_ckp retorna exatamente (hist_ckp[session_id], ""). O segundo argumento é o textbox limpo — se omitir, o campo de mensagem não limpa.

4. "Session ID diferente a cada chamada" — Se o session_id não for fixo (ex: "s1"), cada mensagem cria uma sessão nova e a memória se perde. Use um ID fixo ou gere a partir do IP do usuário.

5. "Thread ID conflita entre abas" — Se dois alunos usam o mesmo thread_id, as memórias se misturam. Use um thread_id único por sessão de demonstração.

💡 Discussão com o Grupo

O Gradio é ideal para protótipos, mas para produção considere: Streamlit (apps mais complexos), FastAPI + React (controle total), ou Docker + NGROK (deploy permanente). O CKP03 aceita qualquer interface — o importante é que funcione e tenha URL pública.
