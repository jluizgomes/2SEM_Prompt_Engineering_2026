EXERCÍCIO 02

Window Memory ⭐⭐

⭐⭐

🎯 Objetivo Pedagógico

🧩 Conceitos Trabalhados

Nenhuma dependência nova.

📋 Passo a Passo no Colab

        # 👉 COMPLETE AQUI: selecione as ultimas window_size*2 mensagens do historico

        pass  # Substitua esta linha

bot_w = WindowChatbot('Voce e assistente especializado.', window_size=2)
for msg in ['Meu nome e Carlos.', 'O que e Python?', 'Voce lembra meu nome?']:

    print(f'U: {msg}\nA (janela={tam}): {resp[:150]}\n')

EXERCÍCIO 03

Summary Memory ⭐⭐⭐

⭐⭐⭐

🎯 Objetivo Pedagógico

Resolver o problema do Window Memory: comprimir o histórico antigo em resumo (não descartar), preservando fatos relevantes com menos tokens.

🧩 Conceitos Trabalhados

🐍 Método privado (_comprimir)🐍 Condicional de gatilho (len >= max_msgs)🐍 Chamada ao LLM dentro de outra classe🤖 Summary Memory🤖 Compressão de contexto🤖 Resumo automático via LLM

⚙️ Preparação Prévia

Nenhuma dependência nova. Esta é a estratégia mais avançada das 3 — reservar mais tempo de acompanhamento.

📋 Passo a Passo no Colab

1Desenhar o fluxo no quadro — historico cresce → atinge limite → LLM resume o antigo → resumo vira SystemMessage extra → historico esvazia parcialmente.
2Alunos completam _comprimir() — A chamada ao LLM para gerar o resumo é o coração do exercício.
3Rodar 7+ mensagens e observar a compressão acontecer — Print do tamanho do resumo (em caracteres) ajuda a visualizar a compressão.

✅ Gabarito

self.resumo = chat(f'Resuma em 2 frases:\n{texto}', max_tokens=100, temperature=0.0)

# EXERCICIO 3 -- SUMMARY MEMORY
# ============================================================

class SummaryChatbot:
    def __init__(self, system_prompt, max_msgs=6):
        self.system = system_prompt
        self.historico = []
        self.resumo = ''
        self.max_msgs = max_msgs

    def _comprimir(self):
        texto = '\n'.join(f"{'U' if t=='user' else 'A'}: {c}" for t,c in self.historico[:-4])
        # 👉 COMPLETE AQUI: chame chat() pedindo resumo em 3 frases e salve em self.resumo
        # self.resumo = chat(f'Resuma em 3 frases:\n{texto}', max_tokens=120, temperature=0.0)
        pass  # Substitua esta linha
        self.historico = self.historico[-4:]

    def chat(self, msg):
        if len(self.historico) >= self.max_msgs:
            self._comprimir()

        # 👉 COMPLETE AQUI: construa contexto = [SystemMessage(content=self.system)]
        # contexto = [SystemMessage(content=self.system)]
        pass  # Substitua esta linha

        if self.resumo:
            contexto.append(SystemMessage(content=f'Resumo: {self.resumo}'))
        for tipo, conteudo in self.historico:
            cls = HumanMessage if tipo == 'user' else AIMessage
            contexto.append(cls(content=conteudo))
        contexto.append(HumanMessage(content=msg))

        resp = llm.invoke(contexto)
        self.historico.extend([('user',msg),('ai',resp.content)])
        return resp.content

⚠️ Erros Comuns

Esquecer que a compressão consome uma chamada extra ao LLM — isso tem custo e latência, é um trade-off, não solução gratuita.
